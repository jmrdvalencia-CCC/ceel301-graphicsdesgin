What is UI & UX?

UI — User Interface Design

The practice of designing the visual and interactive elements a user directly engages with on a screen — buttons, menus, forms, icons, typography, and layout.

UX — User Experience Design

The broader practice of shaping the entire experience a person has while interacting with a digital product — how it feels, how easy it is to use, and whether it achieves the user's goal.

Key Distinction: UI is what it looks like. UX is how it works and feels. Both are required — one without the other fails the user.
