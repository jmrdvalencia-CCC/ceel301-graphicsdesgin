What is Wireframing?

A wireframe is a low-detail, structural blueprint of a web page or screen. It defines the layout and content structure before any visual design decisions are made.

  • What content appears on the page
  • Where each element is positioned
  • How the user navigates between pages
  • What interactions are available
Rule: Never open a design tool before you have a wireframe. Designing without one is like building a house without a floor plan — the structure is guessed, not planned.

Wireframing is to web design what thumbnail sketching is to logo design — the ideation stage that happens before execution.
