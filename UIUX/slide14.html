Activity, Assessment & Summary

Key Takeaways

  • UI is what it looks like. UX is how it works and feels.
  • Wireframing is the planning stage — never skip it.
  • Lo-fi wireframes use boxes, lines, and labels only — no color or images.
  • IA organizes content so users find what they need in 3 clicks or fewer.
  • User flows map the path to complete a task — every page belongs to a flow.
  • Hierarchy in wireframes: size, position, weight, whitespace, contrast.
  • UI patterns are reusable solutions — use conventions before inventing.
  • Every wireframe needs a mobile version — re-prioritized, not shrunk.
  • Annotations explain interactions, states, and dynamic content.

Assessment Questions

  1. What is the difference between UI and UX? Give one example of each for the same website.
  2. List the steps you would take before opening any design software for a homepage.
  3. What is "above the fold" and what must always appear there?
  4. A wireframe has six equally sized buttons. What UX problem does this create?
  5. Describe lo-fi, mid-fi, and hi-fi wireframes. When is each appropriate?
  6. A form has 12 fields and 70% of users abandon it. What changes would you make?
