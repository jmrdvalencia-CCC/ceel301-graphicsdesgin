Graphics Design · Module 05

UI/UX Web Graphics
& Wireframing

From user thinking to paper blueprints — learn how to plan, structure, and communicate web interfaces before a single pixel is designed.

Learning Objectives
  1. 1Define UI and UX design and explain the distinction between the two disciplines.
  2. 2Identify the stages of the web design process and where wireframing fits.
  3. 3Construct a sitemap and user flow diagram for a given brief.
  4. 4Apply hierarchy, layout, and proximity principles to wireframe structure.
  5. 5Produce a lo-fi paper wireframe with annotations and a mobile adaptation.
Reference: Mrantinkovic et al. (2020). 3G Handy Guide: Graphic Designing. 3G E-Learning LLC.
