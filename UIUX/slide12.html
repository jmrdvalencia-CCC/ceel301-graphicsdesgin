UI Patterns & Navigation

UI patterns are reusable solutions to common interface problems. Use established patterns unless you have a validated reason not to — novelty for its own sake increases cognitive load.

Navigation Patterns

PatternBest For
Top nav bar4–7 primary sections
Hamburger menuMobile, secondary nav
Sidebar navDashboards, admin panels
Tab navigationFiltered content, settings
BreadcrumbDeep hierarchies, e-commerce
Footer navLegal, sitemap, social links

Content Patterns

🦸

Hero Section

Full-width banner + CTA. Homepages.

🃏

Card Grid

Repeating cards. Products, articles.

✦

Feature List

Icon + heading + desc. Services.

💬

Testimonial

Quote + name + avatar. Trust.

＋

FAQ Accordion

Expand/collapse. Support pages.

⬜

Modal

Overlay content. Confirmations.

Carousel Warning: Users rarely interact past the first slide. Only use a carousel when content is genuinely sequential — not as a way to avoid making a hierarchy decision.
