Photos are Raster Images
All photographs are made of a fixed grid of pixels. This has direct implications for how they are used in design.
ImplicationDetail
📏 Resolution mattersMust have sufficient pixels for the intended output size
🔍 Enlarging degrades qualityScaling beyond native resolution causes pixelation
💾 Format affects qualityJPG compression reduces quality with each save; RAW preserves all data
🖨️ Print needs 300 dpiWeb standard is 72–96 dpi; print standard is 300 dpi
Web Output
72–96 dpi
JPEG or PNG · RGB color mode
Print Output
300 dpi
TIFF or JPEG · CMYK color mode
⚠️ Rule: Always work from the highest-resolution source. Never enlarge a low-res photo for print.
