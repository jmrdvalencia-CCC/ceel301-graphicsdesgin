RAW vs JPEG
RAW — Master Format
Unprocessed sensor data — all information preserved
Maximum editing flexibility — full control over exposure, WB, color
Large file size: 20–50 MB per image
Use for: all professional work requiring editing
JPEG — Delivery Format
Processed and compressed in-camera — some data discarded
Limited editing range — destructive compression
Small file size: 2–8 MB per image
Use for: quick sharing, web, images needing no editing
⚠️ Rule: JPEG is a delivery format, not an editing format. Each time a JPEG is opened, edited, and saved, it loses quality through recompression.
