Part 4 — Publishing & Platforms
How to Publish on GitHub Pages
Starting after your project is already pushed to GitHub
01
Go to your repository on GitHub
Open github.com → click your repository → make sure your index.html is at the root of the repo.
02
Open Settings
Click the Settings tab at the top of the repository page (not your account settings).
03
Go to Pages
In the left sidebar, scroll down and click Pages under the "Code and automation" section.
04
Set the source branch
Under Branch, select main (or master) → folder: / (root) → click Save.
05
Wait ~1 minute
GitHub builds and deploys your site. Refresh the Pages settings page — a green banner will appear with your live URL.
06
Your live URL is ready
Format: https://username.github.io/repo-name
For a personal portfolio repo named username.github.io, it becomes: https://username.github.io
07
Update anytime with a push
Every time you push changes to the main branch, GitHub Pages automatically rebuilds and redeploys. No manual steps needed.
08
(Optional) Add a custom domain
In Pages settings → Custom domain → enter yourname.dev. Point your domain's DNS to GitHub using a CNAME record.
$ git add . && git commit -m "update portfolio" && git push
