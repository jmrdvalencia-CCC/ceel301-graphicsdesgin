Part 2 — What to Include
GitHub as a Portfolio Tool
For Developers
A well-maintained GitHub profile is a portfolio. Employers check it before the interview.
01
Pin your best repos
Pin 4–6 repositories that represent your strongest work. Unpin tutorial clones.
02
Write a README for every pinned repo
What it does, how to run it, a screenshot. No README = the project doesn't exist to a recruiter.
03
Keep commits consistent
Regular commits show you actually work. Avoid 50 commits in one day then nothing for months.
04
Add a profile README
Create a repo named exactly as your username. Add a short bio, skills, and links.
A Good README Includes
# Project Name
One sentence — what it does.

## Tech Stack
React · Node.js · MongoDB

## How to Run
