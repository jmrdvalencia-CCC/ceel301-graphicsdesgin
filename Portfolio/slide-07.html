Part 2 — What to Include
Writing a Project Case Study
Every project entry must answer these 5 questions
01
What was the problem?
Context and goal — why did this project exist? Who needed it?
02
What did you build?
A brief, plain-language description of the solution — one or two sentences.
03
How did you build it?
Tools, stack, and process. Be specific — "React + Firebase" beats "web technologies".
04
What was the result?
Outcome, metrics, or feedback. If you have numbers, use them.
05
What did you learn?
Honest reflection. What would you do differently? This shows maturity.
If you can answer all 5, you are ready to present that project in an interview.
