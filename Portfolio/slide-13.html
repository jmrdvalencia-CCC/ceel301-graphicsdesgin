Part 4 — Publishing & Platforms
Recommended Stack & Staying Updated
For Students Who Can Code
01
Build with HTML + CSS + JS
Or a framework like React. Keep it simple — a clean static site beats a broken React app.
02
Host on GitHub Pages
Free, fast, version-controlled. Push to main and it's live. The setup itself shows technical skill.
03
Get a custom domain
Namecheap or Cloudflare — around ₱500/year. yourname.dev looks far more professional than username.github.io.
The act of building and deploying your own portfolio site is itself a project worth including.
A Portfolio Is Never Finished
Add new projects after every major course or internship
Update your skills list every semester
Remove weak projects as better ones replace them
Test all links before sharing with anyone
Update it before every job application — not after
