PRINCIPLE 03Simplicity
Every element in a visualization must earn its place. Decorative noise — chartjunk — competes with the data and slows comprehension.
CHARTJUNK — Visual Noise
heavy grid rainbow gradient border box labels on every bar no axis
Decoration competes with data — the viewer's eye has nowhere to land.
CLEAN — Data Speaks
One accent color   Single baseline   Label only where needed
The eye goes straight to April's peak — the story is told in one glance.
Rule: If removing an element doesn't lose information, remove it. Gridlines, borders, 3D effects, and rainbow colors are almost always chartjunk.
