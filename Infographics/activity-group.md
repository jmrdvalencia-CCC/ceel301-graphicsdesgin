# Group Activity — Build a Mini Infographic

## Overview

You are already in your groups. As a group, select one dataset from the options below and design a mini infographic that communicates the data clearly and visually. This activity applies the infographic design principles covered in this module.

---

### Instructions

1. **Stay with your group.** Groups are already formed — no changes will be made.

2. **As a group, select one dataset** from the three options below. Each group must choose a different dataset. Coordinate with other groups to avoid duplicates.

3. **Design your infographic digitally.** Use any design software of your choice (e.g., Canva, Adobe Illustrator, Photoshop, Figma). or Hand-drawn or paper outputs also accepted.

4. **Upload your output to the Google Form provided by your instructor.** Make sure your file is saved as a PNG before uploading.

5. **Present your infographic** to the class in 3 minutes. Be ready to explain your dataset choice, the infographic type used, and the key insight your design communicates.

6. **Each member submits the group output individually.** Every member is required to submit the same PNG file. Use the following filename format:

   ```
   GroupName_Dataset_Surname.png
   ```

   Example: `TeamAlpha_DatasetA_Reyes.png`

### Dataset B — Process Infographic
**The 5-Step Graphic Design Process**

1. **Research** — Understand the problem and the target audience.
2. **Ideate** — Brainstorm and sketch initial concepts.
3. **Design** — Build the chosen concept in design software.
4. **Review** — Evaluate the output and apply revisions.
5. **Deliver** — Export the final file in the correct format.

Suggested infographic type: Timeline or flowchart.

### Dataset C — Comparison Infographic
**Raster vs. Vector Graphics**

| Attribute       | Raster                        | Vector                        |
|-----------------|-------------------------------|-------------------------------|
| Made of         | Pixels                        | Mathematical paths            |
| Scalability     | Loses quality when scaled up  | Scales infinitely without loss|
| File formats    | JPG, PNG, PSD                 | SVG, AI, EPS                  |
| Best used for   | Photography, detailed images  | Logos, icons, illustrations   |

Suggested infographic type: Side-by-side comparison layout.

## Output Requirements

- **Format:** PNG

## Reminders

- Apply a clear visual hierarchy — headline, data, and supporting labels should be easy to read at a glance.
- Use color intentionally. Highlight the most important data point; keep the rest neutral.
- Keep it simple. One key insight communicated well is better than a cluttered layout.
