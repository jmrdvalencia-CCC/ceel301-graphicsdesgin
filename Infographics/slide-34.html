Icon System Consistency
✗ Inconsistent Set
✗ Different stroke weights (1px, 4px, 3px)
✗ Mixed styles (outline + filled)
✗ Different sizes and visual weights
✓ Consistent Set
✓ Same stroke weight (2px throughout)
✓ Same style (all outline)
✓ Same visual weight and grid
4 properties that must match: stroke weight · corner radius · style (outline/filled) · visual weight
