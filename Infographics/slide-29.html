Part 6 — Summary
Key Takeaways
01
Infographic = Visual Translation
Makes complex data faster to understand and easier to remember (Mrantinkovic et al., 2020)
02
6 Types — Choose the Right One
Statistical, informational, timeline, process, geographic, comparison. Wrong type distorts the message.
03
4 Principles of Data Visualization
Accuracy, hierarchy, simplicity, context. Violating accuracy is not a design choice — it's misrepresentation.
04
Color Encodes Meaning
Categorical, sequential, or diverging. Never decorative. Always pair with labels for accessibility.
05
Typography Has a Strict Hierarchy
Title → Subtitle → Axis labels → Data labels → Source. Each level visually distinct.
06
Icon = Most Compressed Communication
A single shape understood without text. Must be clear at small sizes (Mrantinkovic et al., 2020)
07
Icons Need a Consistent System
Same stroke weight, corner radius, grid, and style across all icons in a set.
08
3 Roles of Icons in Infographics
Category markers, pictographs, visual anchors. Never pure decoration.
09
Start with One Headline Message
Write it as one sentence before touching any design tool. Every decision serves this message.
