Part 4 — Layout
Common Layout Patterns
Top-to-Bottom Narrative
Single column, reads like a story. Best for social media and long-form editorial.
Dashboard Grid
Multiple charts in a grid. No single narrative. Best for data-heavy reports.
Timeline
Vertical or horizontal axis with events. Best for history and project phases.
Comparison Columns
Two or three columns, each representing one option. Best for product comparisons.
Map-Centered
Geographic map as primary visual with data overlaid. Best for location-based data.
💡 Sketch the layout on paper first before opening any software. The structure should be decided before any visual design begins.
