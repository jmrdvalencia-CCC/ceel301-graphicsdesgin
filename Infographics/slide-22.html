Construction Steps
01
Identify the Core Shape
Every icon has one primary shape that carries its meaning. Find it first.
02
Build from Primitives
Use only circles, rectangles, and triangles. Use Pathfinder to unite, subtract, intersect.
03
Apply Consistent Stroke Weight
Standard: 2px stroke at 24×24px. Scale proportionally for other sizes.
04
Apply Corner Radius
Decide sharp vs rounded — apply consistently. 2px radius = subtly friendly.
05
Test at Target Size
Zoom to actual display size. If any detail disappears — simplify.
💡 Use the fewest anchor points possible. A smooth curve needs only 2 points — one at each end.
