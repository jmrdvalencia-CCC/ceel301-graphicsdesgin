Part 3 — Icon Abstraction
3 Levels of Icon Abstraction
Realistic (Skeuomorphic)
Closely resembles the real object
Detailed, textured, 3D-like. Feels dated quickly. Hard to read at small sizes.
⚠ Avoid for modern UI
✓ Simplified (Flat)
Recognizable form, no detail
Clean outlines, no texture. Works at any size. Professional standard for modern design.
✓ Recommended
Abstract (Symbolic)
No longer resembles the object
Represents concept through convention. Requires established meaning to be understood.
Use established conventions
💡 Originality in icon design is a liability — lean on established conventions before inventing new ones.
