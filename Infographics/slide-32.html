Deep Dive — Distinction
Infographic vs Data Visualization
Infographic
✓ Combines data, text, icons, narrative
✓ Designed for general public
✓ High design role — layout, illustration, color
✓ Examples: magazine feature, social media post
Data Visualization
✓ Focuses specifically on visual encoding of data
✓ Often technical — may need domain knowledge
✓ Clarity and accuracy over aesthetics
✓ Examples: dashboard chart, scientific graph
💡 All infographics contain data visualization — but not all data visualization is an infographic.
