## PART 1: WHAT IS MOTION GRAPHICS? (25 minutes)

### 1.1 Defining Motion Graphics

**Motion graphics** is the practice of applying animation and cinematic techniques to graphic design elements — typography, logos, icons, shapes, and illustrations — to communicate ideas through movement over time.

*Mrantinkovic et al. (2020)* describe graphic design as a discipline of visual communication — the deliberate arrangement of visual elements to convey a message to an audience. Motion graphics extends this definition by adding a fifth dimension to the designer's toolkit: **time**.

Where static graphic design communicates through a single, fixed composition, motion graphics communicates through a **sequence of compositions** — each frame building on the last to guide the viewer's attention, reinforce a brand identity, or explain a concept that cannot be captured in a single image.

> **Key Distinction:** Motion graphics is not video production and it is not traditional animation. It is graphic design in motion — the same principles of hierarchy, balance, contrast, and typography apply, but they are now applied across a timeline rather than a canvas.

---

### 1.2 Motion Graphics and Graphic Design — The Relationship

Students who have completed the Design Principles, Visual Hierarchy, Color Theory, and Typography modules already possess the foundational language of visual communication. Every principle studied in those modules applies directly to motion graphics — the difference is that in motion, those principles must hold true not just at a single moment, but across every frame of an animation.

| Static Graphic Design | Motion Graphics |
|---|---|
| Single composition | Sequence of compositions over time |
| Hierarchy through size and position | Hierarchy through size, position, and timing |
| Contrast through color and weight | Contrast through movement speed and direction |
| Balance in a fixed layout | Balance maintained across changing states |
| Typography as a static element | Typography as a moving, timed element |
| Color communicates mood | Color transitions reinforce narrative |

> **Key Insight:** *Mrantinkovic et al. (2020)* note that effective graphic design is purposeful — every element earns its place by contributing to the communication goal. In motion graphics, this principle is amplified: every movement must be intentional. Gratuitous animation distracts; purposeful animation clarifies.

---

### 1.3 Where Motion Graphics Appears

Motion graphics is present across every digital touchpoint a brand occupies:

| Context | Example |
|---|---|
| **Logo animation** | A brand's logo animates when a website loads or an app launches |
| **UI transitions** | Screens slide, fade, or morph as a user navigates an interface |
| **Social media content** | Animated posts, stories, and reels |
| **Explainer videos** | Animated diagrams and typography that explain a product or process |
| **Title sequences** | Opening animations for films, podcasts, and YouTube channels |
| **Digital advertising** | Animated banner ads and display campaigns |
| **Broadcast graphics** | Lower thirds, transitions, and overlays in video production |

This module focuses on two of the most foundational and widely applicable applications: **logo animation** and **basic transitions**.

---

### 1.4 The Language of Motion — Core Properties

Every animation — regardless of complexity — is built from four core animatable properties. *Mrantinkovic et al. (2020)* identify the properties of visual elements as the raw material of graphic design; in motion graphics, these properties become variables that change over time.

| Property | What It Controls | Motion Design Use |
|---|---|---|
| **Position** | Where the element is on screen (X and Y coordinates) | Entrances, exits, movement paths |
| **Scale** | The size of the element | Emphasis, reveals, zoom effects |
| **Rotation** | The angle of the element | Spin effects, dynamic entrances |
| **Opacity** | The transparency of the element (0% = invisible, 100% = fully visible) | Fades, reveals, layering |

These four properties are the vocabulary of motion. Every animation technique — no matter how sophisticated — is a combination of changes to these four values over time.

---

### 1.5 Keyframes and Timing

A **keyframe** is a defined state of an element at a specific point in time. The animation software (or browser, or design tool) calculates all the intermediate states between two keyframes — this process is called **interpolation** or **tweening**.

```
Time:     0s ─────────────── 0.5s ─────────────── 1.0s
Opacity:  0%                                       100%
          ↑                                         ↑
       Keyframe 1                              Keyframe 2
       (invisible)                             (fully visible)
```

The animation engine fills in every frame between 0% and 100% opacity over the 0.5-second duration — producing a smooth fade-in.

**Timing terminology:**

| Term | Definition |
|---|---|
| **Duration** | How long the animation takes to complete (in seconds or milliseconds) |
| **Delay** | How long the animation waits before starting |
| **Frame rate (fps)** | How many frames are displayed per second — 24fps (cinematic), 30fps (broadcast), 60fps (UI/web) |
| **Easing** | The acceleration curve of the animation — whether it starts fast, ends fast, or moves at a constant speed |

## PART 2: THE PRINCIPLES OF ANIMATION IN MOTION DESIGN (25 minutes)

### 2.1 The 12 Principles of Animation

The 12 Principles of Animation were originally developed by Disney animators Ollie Johnston and Frank Thomas in 1981 to describe the techniques that make character animation feel believable and alive. *Mrantinkovic et al. (2020)* identify these principles as foundational to understanding how visual elements communicate through movement — they apply equally to logo animation and UI transitions as they do to character animation.

This module focuses on the six principles most directly applicable to motion graphics and logo animation.

---

### 2.2 Easing (Slow In / Slow Out)

**Easing** is the most important principle in motion design. In the physical world, objects do not start and stop instantaneously — they accelerate from rest and decelerate before stopping. Animation that ignores this feels mechanical and unnatural.

**Easing types:**

| Easing Type | Behavior | When to Use |
|---|---|---|
| **Linear** | Constant speed throughout | Mechanical, technical contexts — rarely used in brand animation |
| **Ease In** | Starts slow, ends fast | Elements exiting the screen |
| **Ease Out** | Starts fast, ends slow | Elements entering the screen — the most natural feel |
| **Ease In-Out** | Starts slow, speeds up, ends slow | Elements moving from one position to another |
| **Custom curve** | Designer-defined acceleration | Signature brand motion — distinctive personality |

> **Rule:** Never use linear easing for brand animation. Linear motion reads as robotic and cheap. Ease Out is the default for any element entering the screen *(Mrantinkovic et al., 2020)*.

---

### 2.3 Anticipation

**Anticipation** is a small preparatory movement that signals to the viewer that a larger action is about to occur. It primes the eye and makes the subsequent movement feel intentional rather than sudden.

**Examples in motion graphics:**
- A logo element pulls back slightly before launching forward into its final position
- A letter compresses slightly before bouncing into place
- An icon shrinks briefly before expanding to full size

Anticipation is the motion equivalent of a visual pause — it creates expectation, and expectation makes the payoff more satisfying.

---

### 2.4 Squash and Stretch

**Squash and stretch** describes the deformation of an object to convey weight, elasticity, and energy. A rigid object that does not deform reads as heavy and mechanical. An object that squashes on impact and stretches during movement reads as light, energetic, and alive.

In logo animation, squash and stretch is applied subtly — a letterform that compresses slightly as it lands, or a shape that stretches as it moves across the screen. Overuse makes a brand feel cartoonish; underuse makes it feel stiff.

> **Application:** Squash and stretch is most effective in logo animations for brands that want to communicate energy, playfulness, or approachability. It is inappropriate for brands communicating authority, precision, or luxury *(Mrantinkovic et al., 2020)*.

---

### 2.5 Staging

**Staging** is the principle that the viewer's attention should be directed to the most important element at any given moment. In static design, staging is achieved through hierarchy — size, contrast, and position. In motion graphics, staging is achieved through **timing** — only one element moves at a time, or the most important element moves first.

**Staging rules for motion graphics:**
- Never animate two equally important elements simultaneously — the viewer cannot watch both
- The element that moves first receives the most attention
- Use stillness as a staging tool — a static element surrounded by moving elements draws the eye through contrast

---

### 2.6 Follow Through and Overlapping Action

**Follow through** describes the continuation of movement after the primary action has stopped — a flag continues to wave after the wind stops; a ponytail continues to swing after the head stops turning.

**Overlapping action** describes the principle that different parts of an object do not all move at the same time — they move in sequence, with each part slightly delayed from the previous.

In logo animation, these principles are applied when a logo has multiple components — letters, shapes, or icons — that animate in sequence rather than all at once. The slight delay between each element creates a sense of organic, natural movement rather than mechanical synchronization.

---

### 2.7 Timing and Weight

**Timing** in animation refers to the number of frames allocated to an action — more frames means slower movement; fewer frames means faster movement. The timing of an animation communicates the **weight** and **character** of the object being animated.

| Timing | Communicates |
|---|---|
| Fast (fewer frames) | Light, energetic, urgent |
| Slow (more frames) | Heavy, deliberate, premium |
| Sudden start, slow end | Confident, assertive |
| Slow start, sudden end | Building tension, impact |

> **Brand Application:** A luxury brand's logo animation should move slowly and deliberately — fast animation communicates energy but undermines the perception of quality and exclusivity. A tech startup's logo animation can move quickly and crisply — it communicates efficiency and modernity *(Mrantinkovic et al., 2020)*.

## PART 3: LOGO ANIMATION (25 minutes)

### 3.1 What is Logo Animation?

A **logo animation** (also called a logo reveal or logo sting) is a short animated sequence — typically 1 to 5 seconds — in which a brand's logo is introduced to the viewer. It is one of the most common and commercially important applications of motion graphics.

Logo animations appear:
- At the start of video content (YouTube, social media, presentations)
- When a website or app loads (splash screens, loading states)
- At the end of video content (outro sequences)
- In digital advertising

*Mrantinkovic et al. (2020)* identify the logo as the primary visual anchor of a brand identity — the single element that must communicate the brand's personality, values, and positioning at a glance. A logo animation extends this communication into time: it does not just show the logo, it **performs** the brand's personality.

---

### 3.2 Logo Animation Styles

| Style | Description | Brand Personality |
|---|---|---|
| **Fade In** | Logo appears from transparent to opaque | Elegant, minimal, understated |
| **Draw / Reveal** | Logo is drawn on screen as if by a pen | Crafted, artisanal, personal |
| **Build** | Logo assembles from its component parts | Structured, engineered, precise |
| **Morph** | A shape transforms into the logo | Creative, fluid, innovative |
| **Kinetic type** | Letters animate individually into position | Dynamic, editorial, modern |
| **Bounce / Spring** | Logo enters with elastic energy | Playful, approachable, youthful |
| **Glitch** | Logo appears with digital distortion effects | Tech-forward, edgy, disruptive |
| **Particle** | Logo forms from or dissolves into particles | Premium, cinematic, high-production |

> **Rule:** The animation style must be consistent with the brand's visual identity and personality. A law firm's logo should not bounce. A children's toy brand's logo should not glitch. The motion is an extension of the brand — not a separate creative decision *(Mrantinkovic et al., 2020)*.

---

### 3.3 Anatomy of a Logo Animation

A well-structured logo animation follows a three-act structure:

```
ACT 1: INTRO          ACT 2: REVEAL         ACT 3: HOLD
─────────────────     ─────────────────     ─────────────────
0s ──────── 0.5s      0.5s ──────── 1.5s    1.5s ──────── 3.0s

Supporting elements   Logo animates into    Logo holds in final
enter or context      its final position    position — viewer
is established        using chosen style    reads and registers
```

**Timing guidelines:**

| Element | Recommended Duration |
|---|---|
| Total animation | 1.5 – 4 seconds |
| Logo reveal | 0.5 – 1.5 seconds |
| Hold (logo visible, static) | 0.5 – 1.5 seconds |
| Tagline reveal (if present) | 0.3 – 0.8 seconds after logo |

---

### 3.4 Storyboarding a Logo Animation

Before animating, a **storyboard** maps the sequence of states the logo passes through. Each frame in the storyboard represents a keyframe in the animation.

**Storyboard format:**

```
Frame 1 (0s)          Frame 2 (0.5s)        Frame 3 (1.0s)        Frame 4 (1.5s)
──────────────        ──────────────        ──────────────        ──────────────
[  Empty screen  ]    [ Logo at 0%   ]      [ Logo at 80%  ]      [ Logo at 100% ]
                      [ opacity,     ]      [ opacity,     ]      [ opacity,     ]
                      [ scale 0.8    ]      [ scale 1.05   ]      [ scale 1.0    ]
                                                                   [ HOLD         ]

Notes: Fade in +      Ease Out scale        Slight overshoot      Final position
       scale up       from below            (squash/stretch)      registered
```

Each frame includes:
- A sketch of the visual state
- The timestamp
- Notes on easing and property values
- Any sound design cues (if applicable)

---

### 3.5 Logo Animation and Brand Consistency

*Mrantinkovic et al. (2020)* emphasize that brand consistency — the application of the same visual language across all touchpoints — is a core responsibility of the graphic designer. A logo animation is a brand touchpoint, and it must adhere to the same rules as all other brand applications.

**Brand consistency checklist for logo animation:**

| Element | Requirement |
|---|---|
| **Color** | Only brand-approved colors used in the animation |
| **Typography** | Wordmark uses the correct typeface — no substitutions |
| **Proportions** | Logo proportions are never distorted beyond the animation's intentional squash/stretch |
| **Clear space** | The logo's clear space rules are respected in the final hold frame |
| **Speed** | Animation speed is consistent with the brand's personality |
| **Sound** | If a sound effect is used, it must match the visual character of the animation |

## PART 4: BASIC TRANSITIONS (20 minutes)

### 4.1 What Are Transitions?

A **transition** is an animated change between two states — two screens, two slides, two sections of a page, or two scenes in a video. Transitions serve a functional purpose: they communicate to the viewer that something has changed, and they guide the eye from the old state to the new state.

*Mrantinkovic et al. (2020)* identify continuity — the sense that a design holds together as a unified whole — as a core quality of effective visual communication. Transitions are the motion design tool that maintains continuity across change.

> **Rule:** A transition should never draw attention to itself. If the viewer notices the transition, it has failed. A successful transition is felt, not seen — it makes the change feel natural and inevitable.

---

### 4.2 Transition Types

| Transition | Description | Best Used For |
|---|---|---|
| **Cut** | Instant change — no animation | Fast-paced content, technical interfaces |
| **Fade** | Element fades out; new element fades in | Neutral, universal — works in any context |
| **Dissolve** | Old and new elements overlap during the transition | Soft, cinematic — editorial and brand content |
| **Slide** | New element slides in from a direction; old element slides out | Navigation — communicates spatial relationship |
| **Push** | New element pushes old element off screen | Strong directional navigation |
| **Wipe** | A line sweeps across the screen, revealing the new state | Broadcast graphics, presentations |
| **Zoom** | Camera zooms into or out of an element to transition | Depth, focus, emphasis |
| **Morph** | Elements transform into each other | Conceptual connections, brand storytelling |
| **Reveal** | A mask or shape expands to reveal the new state | Dramatic reveals, brand moments |

---

### 4.3 Directional Logic in Transitions

Transitions that involve movement — slides, pushes, wipes — must follow a consistent **directional logic** that matches the spatial model of the interface or narrative.

**Spatial navigation model:**

```
                    ↑ Back / Up in hierarchy
                    │
← Previous page     │     Next page →
                    │
                    ↓ Forward / Down in hierarchy
```

**Rules:**
- Moving **forward** in a sequence (next page, next step): new content enters from the **right**
- Moving **backward** (previous page, back button): new content enters from the **left**
- Moving **deeper** into a hierarchy (opening a detail page): new content enters from the **bottom** or zooms in
- Moving **up** in a hierarchy (returning to a parent page): new content enters from the **top** or zooms out

Violating directional logic — for example, using a right-to-left slide when navigating forward — creates spatial disorientation. The viewer's mental model of the interface is disrupted.

---

### 4.4 Transition Timing

The duration of a transition directly affects the perceived quality and personality of the interface or content.

| Duration | Effect | Use Case |
|---|---|---|
| **< 100ms** | Imperceptible — feels like a cut | Not recommended — too fast to register |
| **100 – 200ms** | Crisp, responsive | UI micro-interactions, button states |
| **200 – 400ms** | Standard — feels natural | Page transitions, modal opens/closes |
| **400 – 600ms** | Deliberate, considered | Brand moments, feature reveals |
| **> 600ms** | Slow — risks feeling sluggish | Only for cinematic or editorial contexts |

> **Rule:** UI transitions should never exceed 400ms. Users are trying to accomplish a task — a slow transition is an obstacle, not a feature. Reserve longer durations for brand animation contexts where the viewer's attention is the goal, not a byproduct *(Mrantinkovic et al., 2020)*.

---

### 4.5 Transition and Hierarchy

Transitions can reinforce visual hierarchy by directing the viewer's attention to the most important element in the new state. This is achieved through **staggered animation** — elements in the new state do not all appear simultaneously; they appear in order of importance.

**Staggered entrance example:**

```
Time:    0ms ──── 200ms ──── 350ms ──── 450ms ──── 550ms
         │         │           │           │           │
         Screen    Heading     Subheading  Body text   CTA button
         appears   fades in    fades in    fades in    fades in
```

The heading appears first because it is the most important element. The CTA appears last because it is the action — the viewer should read the content before being prompted to act.

---

### 4.6 Transitions in Presentations and Slide Decks

Slide transitions are the most common context in which students will apply transition design. *Mrantinkovic et al. (2020)* identify presentations as a key deliverable of the graphic designer — the ability to communicate ideas clearly through a structured visual sequence is a professional competency.

**Presentation transition guidelines:**

| Guideline | Reason |
|---|---|
| Use one transition type throughout the entire deck | Consistency — multiple transition types feel chaotic |
| Use a simple fade or slide — avoid complex effects | Complex transitions distract from content |
| Keep duration at 200 – 300ms | Fast enough to feel responsive; slow enough to register |
| Use directional slides for sequential content | Reinforces the forward progression of the narrative |
| Use a fade for non-sequential jumps | A slide implies spatial relationship — a fade does not |
| Never use random transitions | Random transitions communicate a lack of design intent |

## PART 5: MOTION DESIGN PRINCIPLES IN PRACTICE (20 minutes)

### 5.1 Motion and Brand Personality

Every brand has a personality — a set of human characteristics that define how the brand communicates. *Mrantinkovic et al. (2020)* identify brand personality as a core output of the graphic design process, expressed through color, typography, imagery, and layout. In motion graphics, brand personality is expressed through the **character of movement**.

| Brand Personality | Motion Characteristics |
|---|---|
| **Luxury / Premium** | Slow, deliberate, smooth ease-in-out; minimal movement; long holds |
| **Playful / Youthful** | Bouncy, springy, squash and stretch; bright color transitions; fast timing |
| **Tech / Innovative** | Crisp, precise, geometric; glitch or particle effects; sharp easing |
| **Trustworthy / Professional** | Clean fades and slides; no decorative motion; consistent timing |
| **Creative / Artistic** | Fluid morphs, hand-drawn reveals; irregular timing; expressive curves |
| **Energetic / Athletic** | Fast, impactful; strong directional movement; minimal hold time |

---

### 5.2 Common Motion Design Mistakes

| Mistake | Problem | Correction |
|---|---|---|
| **Too many simultaneous animations** | Viewer cannot focus — attention is split | Stagger animations; move one element at a time |
| **Linear easing throughout** | Feels mechanical and cheap | Apply ease-out for entrances, ease-in for exits |
| **Animation that serves no purpose** | Distracts from content; increases cognitive load | Every animation must serve a communication goal |
| **Inconsistent timing** | Feels unplanned and amateurish | Establish a timing system and apply it consistently |
| **Animation that contradicts brand personality** | Undermines brand identity | Define motion guidelines before animating |
| **Transitions that are too slow** | Frustrates users; feels sluggish | Keep UI transitions under 400ms |
| **Logo animation that distorts the logo** | Violates brand guidelines | Respect logo proportions and clear space rules |
| **No hold on the final logo frame** | Viewer cannot register the brand | Always hold the final logo state for at least 0.5 seconds |

---

| Tool | Type | Use Case |

## PART 6: ACTIVITY & SUMMARY (25 minutes)

### 6.1 Key Takeaways

1. **Motion graphics is graphic design in time** — the same principles of hierarchy, contrast, balance, and typography apply, but across a timeline rather than a canvas *(Mrantinkovic et al., 2020)*.
2. **Every animation is built from four properties** — position, scale, rotation, and opacity. All motion design is a combination of changes to these values over time.
3. **Easing is the most important principle** — linear motion reads as mechanical. Ease Out for entrances; Ease In for exits; Ease In-Out for movement between positions.
4. **A logo animation performs the brand's personality** — the style, speed, and character of the motion must be consistent with the brand's visual identity.
5. **Transitions communicate spatial and narrative relationships** — directional logic must be consistent throughout an interface or presentation.
6. **Timing determines perceived quality** — slow motion reads as premium; fast motion reads as energetic. Match timing to brand personality.
7. **Stagger animations to reinforce hierarchy** — the most important element moves first; the CTA moves last.
8. **Every animation must serve a purpose** — gratuitous motion distracts; purposeful motion clarifies.
9. **UI transitions must be fast** — never exceed 400ms for interface transitions. Users are completing tasks, not watching a performance.
10. **Hold the final logo frame** — always allow at least 0.5 seconds of static hold so the viewer can register the brand.

3. A brand describes itself as "premium, calm, and trustworthy." Describe the motion characteristics — timing, easing, style — you would use for its logo animation. Justify each decision.

### 6.3 Effective vs. Ineffective Motion Design

| Feature | Effective | Ineffective |
|---|---|---|
| **Easing** | Ease Out for entrances; Ease In for exits | Linear easing throughout |
| **Timing** | Matched to brand personality and context | Arbitrary — same duration for all elements |
| **Logo hold** | Final frame held for 0.5 – 1.5 seconds | Logo disappears immediately after reveal |
| **Stagger** | Elements animate in order of hierarchy | All elements animate simultaneously |
| **Transitions** | One consistent type throughout | Different transition on every slide |
| **Directional logic** | Forward = right; backward = left | Random directions with no spatial logic |
| **Brand consistency** | Motion style matches brand personality | Animation style contradicts brand identity |
| **Purpose** | Every animation serves a communication goal | Decorative animation with no function |
